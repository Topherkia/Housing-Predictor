# Melbourne Housing Dataset

The project uses the Melbourne Housing Snapshot dataset.

The dataset contains property information including:

- suburb
- property type
- rooms
- price
- distance from Melbourne CBD
- bedrooms
- bathrooms
- car spaces
- land size
- building area
- year built
- geographic coordinates
- region

The dataset represents historical property data.

A machine-learning prediction is an estimate based on patterns learned from the dataset and should not be treated as a current professional property valuation.
